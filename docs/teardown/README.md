## Design problems to verify against the shots

These are the problems the project is aiming at. Confirm or correct each one from the screenshots. Do not treat this list as a measured finding until the images are in this folder.

1. **Clutter.** Ads, related-set modules, and upgrade prompts sit on the set page before studying starts. Recall's study screen is one question.
2. **Passive flipping.** Flashcards show the term, then the definition. That is recognition. Recall changes the widget as the level moves from recognize, to recall, to apply.
3. **The same format every time.** A card stays a card. Recall's contract is eight widgets, and the question route is given `recentWidgets` so the next question can take a different shape.
4. **Paywalled features.** Learn and other modes sit behind upgrade prompts. Recall's session, including `explain` grading, is part of the same flow.
